### Astana International Financial Centre (AIFC) — ОПТИМАЛЬНЫЙ ВЫБОР

| Параметр | Статус |
|----------|--------|
| Юридическая система | **British Common Law** (не казахстанское право!) |
| Регулятор | AFSA (Astana Financial Services Authority) |
| Налог на прибыль | **0%** до 2066 года |
| Налог на дивиденды | **0%** |
| НДС | **0%** на финансовые услуги |
| Доступ иностранцев | 100% иностранное владение |
| Язык | Английский (официальный язык AIFC) |
| Регистрация | 2-4 недели |
| Репутация | IOSCO признал AIFC одним из мировых лидеров (2025) |
| Digital Assets | Полностью легальны с 01.01.2026 |
| Кто уже там | Binance, Bybit, WhiteBIT, ATAIX, ITS |

### Что нужно для AIFC компании:

```
1. AIFC Private Company (Ltd)
   - Регистрация через AFSA
   - Минимальный капитал: зависит от лицензии
   - Директор: может быть founder лично
   - Beneficial owner: полное раскрытие (это нормально)
   
2. Лицензия Digital Asset Service Provider (DASP) — опционально
   Нужна ТОЛЬКО если компания:
   - Хранит крипто-активы пользователей (custody)
   - Проводит обмен крипто-фиат
   - Управляет крипто-инвестициями
   
   НЕ НУЖНА если:
   - Токен $SIG — utility token на децентрализованной бирже (Uniswap)
   - Компания не хранит средства пользователей
   - Игра не проводит фиатные расчёты напрямую
   
3. Stripe/Ramp — для premium платежей
   - Stripe НЕ требует крипто-лицензии
   - Это обычный платёжный процессинг
   - Вывод на банковский счёт AIFC-компании
```
