## PRODUCTION TIPS

### Visual Style
- Dark theme (matches game aesthetic)
- Smooth transitions between screens
- Zoom into key elements (buttons, stats, entities)
- Show real gameplay, not mockups

### Audio
- Background music: subtle, electronic, atmospheric
- Sound effects from the game (battle sounds, victory)
- Clear voiceover (no mumbling)

### Editing
- Fast cuts during gameplay (keeps attention)
- Slow down for key stats ($131M ARR, 40% burn)
- Add text overlays for key numbers
- End with clear CTA (website, Discord)

### Thumbnail
- Entity emoji (💀 or 👺)
- Text: "GameFi 2.0"
- Dark background with cyan glow
