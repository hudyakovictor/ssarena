# SIGNAL ARENA · VISUAL SYSTEM V3
## Переосмысление визуальной части: от «тёмного дашборда» к игровому кадру

> Версия 3.0 · Прототип на Phaser 3 + TypeScript + Vite
> Директория: `game/` · запуск: `cd game && npm i && npm run dev`

---

## 0 · Почему предыдущая версия получила низкую оценку

Диагноз по коду и скриншотам старой сборки (`src/screens/*.tsx`):

| # | Проблема | Что это давало на глаз |
|---|----------|------------------------|
| 1 | Интерфейс = **веб-админка**, а не игра | Сайдбар + карточки + таблицы. Ноль игрового кадра |
| 2 | `lightweight-charts` — DOM-виджет поверх страницы | График «чужой»: не участвует в камере, тряске, партиклах |
| 3 | Tailwind-дефолты | Скруглённые карточки, одинаковые отступы, «как у всех» |
| 4 | Неон без иерархии | Всё светится → не светится ничего. Глазу не за что зацепиться |
| 5 | Иконки `lucide-react` | Стоковый набор, ноль айдентики |
| 6 | Нет драматургии | Действие игрока не имеет последствия в кадре: нет вспышки, вердикта, звука |
| 7 | Текст функциональный | «Начать бой», «Ваш баланс» — голос бренда потерян в UI |
| 8 | Плоскость | Один слой. Нет параллакса, глубины, атмосферы |
| 9 | Нет петли | Экраны есть, цикла «зашёл → сыграл → получил → вернулся» нет |
| 10 | Меню = список ссылок | Город из концепт-арта не использован как навигация |

Вывод: чинить точечно бессмысленно. Меняется **носитель** — интерфейс переезжает
внутрь игрового движка и становится частью кадра.

## 1 · Формула продукта

**TradingView** (точность данных) × **Hearthstone** (драматургия хода) × **Duolingo** (петля привычки)
на подложке **панк-таблоидной криптосатиры**.

| Источник | Что берём | Где видно |
|----------|-----------|-----------|
| TradingView | честный OHLC, объём, сетка, ценовые метки, кросс-хейр | `ui/CandleChart.ts` |
| Hearthstone | ход имеет вес: таймер, вспышка, «печать» вердикта, партиклы, звук | `scenes/ArenaScene.ts` |
| Duolingo | дорожка уроков, узлы, серия дней, дневная норма, сердца | `scenes/AcademyScene.ts` |
| Таблоид | газетная типографика, кикеры, бегущая строка «СРОЧНО» | `scenes/HudScene.ts` |

## 2 · Дизайн-система (`src/core/theme.ts`)

### 2.1 Цвет — носитель смысла, не украшение
- Подложка не «чёрная», а **закопчённый асфальт с синевой** (`#07080c → #232a3a`): в тёмной сцене чистый чёрный выглядит дырой.
- Тёплая **бумага** (`#e8e2d6`) — таблоидный слой поверх холодного города. Контраст температур = глубина без лишних цветов.
- Смысловые: LONG `#35d68a`, SHORT `#fb4b6b`, SIGNAL `#2ad4e6`, GOLD `#f5b13d`, GRAPE `#9b6cff`.
- **Каждый район города имеет постоянный цвет** — цвет здания = цвет экрана = цвет бейджа. Память места.

### 2.2 Типографика — ровно три семейства
| Роль | Шрифт | Зачем |
|------|-------|-------|
| Заголовки | **Oswald** | Узкий гротеск = газетная полоса, вмещает капс |
| Данные | **JetBrains Mono** | Цифры не «пляшут» при обновлении |
| Тело | **Inter** | Читаемость длинных разборов |

7 ступеней шкалы, ничего между ними. Кикеры — капс 10px с разрядкой 3px.

### 2.3 Форма и ритм
- Сетка 4pt, радиусы 2 / 6 / 14.
- **Скошенный угол панели** вместо скругления — узнаваемая форма, не Bootstrap.
- Угловые «засечки-крепления» на каждой панели — ощущение материала.
- Единая физика движения: 90 / 160 / 260 / 420 / 640 мс, `Cubic.easeOut`.

### 2.4 Гранж — процедурный, не картинка
Все текстуры считаются на канвасе в `core/textures.ts`: зерно, бумага с волокнами,
полутон, виньетка, царапины, искры, пыль. **Ноль внешних PNG** — весит ноль
килобайт, масштабируется под любой DPR.

### 2.5 Иконки — своя сетка
20+ иконок нарисованы path-командами на сетке 24×24, штрих 2px (`core/textures.ts`).
Ни одной стоковой. Растеризуются в любой размер и цвет по требованию.

## 4 · Почему свой CandleChart, а не библиотека

`ui/CandleChart.ts` — Graphics-рендер. Что стало возможно и было невозможно раньше:

1. **Туман войны** над будущими свечами — механика скрытия ответа.
2. **Анимация «печати»** графика слева направо при входе в раунд.
3. **Драматичное раскрытие** будущего с тряской камеры.
4. **Вспышка результата** прямо в плоскости графика.
5. График **живёт в камере сцены**: fade, shake, партиклы поверх — единый кадр.
6. Ноль DOM-узлов → нет рассинхрона канваса и HTML при ресайзе.

Сохранено от «взрослого» терминала: OHLC-тела с тенями, гистограмма объёма,
ценовые метки на оси, пунктирная линия последней цены с ярлыком, уровни.

## 5 · Голос интерфейса

Каждая строка написана по формуле
**[драматичный заголовок] + [простая правда] + [неприятный вывод]** (`content/lore.ts`).

- Проигрыш: «РЫНОК ПРИНЯЛ ТВОЁ РЕШЕНИЕ. И оставил его себе.»
- Нет денег: «Недостаточно $SIG. Рынок сочувствует формально.»
- Сброс профиля: «Личное дело уничтожено. Департамент всё равно помнит.»
- Сердца кончились: «Терпение закончилось. Департамент рекомендует прогулку.»

Правило: игрок не герой, а участник системы. Обучение слегка угрожает.

---

## 6 · Звук без единого файла

`core/sfx.ts` — синтез на WebAudio: клики реле, тональные подтверждения,
шумовой удар на провале, арпеджио на победе. Короткие, тихие, не раздражают
на двухсотом раунде. Отключаются в Киоске.

---

## 7 · Детерминизм — фундамент Proof of Skill

`core/scenario.ts` на seedrandom: один seed → один и тот же график и один
правильный ответ. Следствия: честное сравнение игроков в лиге, воспроизводимые
баг-репорты, ежедневный «выпуск» одинаковый для всех (`dailySeed()`).

Пять режимов рынка: тренд вверх / тренд вниз / боковик / **ловушка** / **паника**.
Ловушка и паника учат главному: лучшая сделка — часто её отсутствие (`WAIT`).
