## 🔴 КРИТИЧЕСКИЙ АНАЛИЗ: DUAL-TOKEN ARCHITECTURE

### Проблема single-token модели
```
$SIG используется для ВСЕГО:
  ├── Premium подписка (цена чувствительна)
  ├── Косметика (цена чувствительна)
  ├── Tournament entry fees (цена чувствительна)
  ├── Governance (требует холдинга)
  ├── Earning rewards (эмиссия)
  └── Marketplace (P2P)

Парадокс:
  Если $SIG растёт → premium становится дорогим → меньше конверсий
  Если $SIG падает → rewards обесцениваются → меньше мотивации играть
```

### Решение: $SIG (Governance) + ⚡ATTN (Utility soft-currency)

```
$SIG — Governance Token (фикс. supply 1B)
  ├── Торгуется на биржах
  ├── Governance (DAO voting)
  ├── Staking rewards
  ├── Крупные покупки (Season Pass, Limited Skins)
  └── НЕ используется для микротранзакций

⚡ATTN — Attention Credits (utility, НЕ токен)
  ├── Внутриигровая soft-currency
  ├── Не торгуется на биржах (off-chain)
  ├── Зарабатывается: daily puzzle, бои, турниры
  ├── Тратится: AP replenish, cosmetics, entry fees
  ├── Конвертация: $SIG → ATTN (односторонний burn!)
  └── Pegged к фиату через oracle: 1 ATTN ≈ $0.01
```

### Миграция (безболезненная)

1. **Сегодня:** $SIG используется для всего (mock)
2. **Pre-Beta:** ATTN внедряется как soft-currency. $SIG → ATTN через burn
3. **Beta:** ATTN используется для микротранзакций. $SIG для крупных
4. **TGE:** $SIG листится. ATTN остаётся off-chain utility
5. **DAO:** $SIG holders голосуют. ATTN users играют.

**Выгода:**
- Игроки не чувствуют волатильность токена
- Premium становится предсказуемым по цене
- $SIG burn увеличивается (конвертация в ATTN = burn)
- Dual-token = industry standard → проще привлекать инвесторов
- Соответствует рекомендациям GameFi 2.0
