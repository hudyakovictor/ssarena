## 🎯 ПРИНЦИП: НЕ СПЕШИТЬ

```
Ошибка 90% проектов: листинг на бирже ДО того как есть продукт и сообщество.

Правильный путь:
  1. Продукт работает (играют реальные игроки) ✅
  2. Retention > 30% D7 ✅
  3. Сообщество > 10K в Discord/Twitter
  4. Органический спрос на токен (игроки хотят $SIG для premium)
  5. ТОЛЬКО ТОГДА → DEX листинг
  6. Органический объём на DEX растёт
  7. ТОЛЬКО ТОГДА → CEX листинг
```

## 📈 ФАЗЫ ЛИСТИНГА

### Фаза 0: Pre-TGE (Token Generation Event) — Месяц 0-1

```
Что: Создание токена $SIG ERC-20 на Ethereum
Где: НИГДЕ не торгуется
Кто имеет: Только команда (vesting) и early contributors (airdrop)
Цена: Нет рыночной цены

Действия:
  - Аудит контракта (OpenZeppelin / Trail of Bits)
  - Airdrop ранним тестерам и community builders
  - Whitepaper / токеномика опубликованы
```

### Фаза 1: DEX Launch — Месяц 1-2

```
Где:
  1. Uniswap V3 (Ethereum) — основной пул
  2. QuickSwap (Polygon) — дешёвые транзакции для игроков

Параметры пула:
  - Начальная ликвидность: $500,000 (50% ETH, 50% $SIG из treasury)
  - Начальная цена: определяется рынком
  - LP токены: заблокированы на 1 год (Team Finance / Unicrypt)
  - Fee tier: 0.3% (стандарт)

Liquidity lock proof:
  - Ссылка на Unicrypt/Team Finance
  - "Ликвидность заблокирована на 365 дней"
  - Это ОБЯЗАТЕЛЬНО для доверия сообщества

DeFi интеграции:
  - DexScreener: мониторинг цены
  - DexTools: трекинг объёмов
  - CoinGecko: листинг (бесплатно, нужно подать заявку)
  - CoinMarketCap: листинг (бесплатно)
```

### Фаза 2: Community Growth — Месяц 2-6

```
Цель: organically растущий объём на DEX

Что делать:
  - Premium подписка за $SIG → постоянный buy pressure
  - Season Pass за $SIG → регулярный спрос
  - Сжигание токенов из revenue → снижение предложения
  - НЕ проводить маркет-мейкинг (это манипуляция)

Метрики для отслеживания:
  - Daily volume на DEX
  - Количество уникальных держателей
  - Burn / Emission ratio
  - Топ-10 holders concentration (должна снижаться)
```

### Фаза 3: Tier-2 CEX — Месяц 6-12

```
Условия для подачи заявки:
  - 10,000+ держателей токена
  - $100K+ daily DEX volume
  - 50K+ community members
  - Продукт работает > 3 месяцев

Биржи (в порядке приоритета):
  1. MEXC — самый доступный, хорошие объёмы
  2. Gate.io — хорошая репутация, строгий due diligence
  3. Bybit — растущая биржа, web3-friendly
  4. KuCoin — большое комьюнити, требует due diligence
  5. Bitget — агрессивный рост, копитрейдинг

Что биржи спросят:
  - Юридическое заключение (token ≠ security)
  - Аудит смарт-контракта
  - Команда (кто вы?)
  - Продукт (что уже работает?)
  - Сообщество (сколько людей?)
  - Roadmap (куда идёте?)
  - Tokenomics (как распределены токены?)
  - Market maker план (кто обеспечивает ликвидность?)

Стоимость листинга:
  - MEXC: $0 (при хороших метриках) до $50K
  - Gate.io: $0-$80K
  - Bybit: $50K-$150K
  - KuCoin: $100K-$300K

ВАЖНО: Никогда не платить за листинг из кармана.
Только из treasury/marketing бюджета.
```

### Фаза 4: Tier-1 CEX — Месяц 12-24

```
Условия:
  - 100K+ держателей
  - $1M+ daily volume
  - 200K+ community
  - Продукт работает > 1 года
  - Revenue > $1M ARR

Биржи:
  1. Coinbase — самый престижный. ОЧЕНЬ строгий due diligence
  2. Binance — самый большой объём
  3. OKX — силён в DeFi/web3
  4. Kraken — репутация, regulation-friendly

Coinbase listing checklist:
  - Юридическое заключение от топ-фирмы
  - 2+ аудита безопасности
  - НЕТ признаков security (Howey test пройден)
  - Прозрачная команда
  - Работающий продукт с реальными пользователями
  - GitHub активность
  - НЕТ маркет-мейкинга и манипуляций
```
